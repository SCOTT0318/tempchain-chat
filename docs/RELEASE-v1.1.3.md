# TEMPCHAIN Chat v1.1.3

Windows 설치 오류를 수정하고 버전 확인·자동 업데이트를 제공하는 정식 릴리스입니다. 설치 검증에서 오류가 발견된 v1.1.2를 대체합니다.

## 설치 및 업데이트 수정

- 설치기 압축 방식을 zlib로 변경하고 중복 데이터 최적화 비활성화
- 빌드 중간 파일을 동기화 폴더 밖의 로컬 staging에서 생성
- 배포 전에 **실제 설치기로 파일 472개를 별도 검증 폴더에 추출하고 원본 SHA-256과 전부 비교**. 불일치하거나 추출에 실패하면 배포물 생성 중단
- 업데이트 설치 전에 기존 앱 파일 백업. 설치 실패 시 원래 파일과 설치 등록 버전을 복원하고 오류·복원 결과 기록
- 사용자 설정과 기존 바로가기 유무 보존

## 버전 확인과 자동 업데이트

설정의 **버전 및 업데이트**에서 현재 버전·최신 정식 버전·확인 및 다운로드 상태를 봅니다. **새 버전 자동 확인 및 다운로드**는 기본 켜짐이며 앱 시작 시와 실행 중 6시간마다 동작합니다. 수동 **업데이트 확인**도 가능합니다.

다운로드가 준비되면 **업데이트 및 재시작**으로 적용합니다. 작성 중인 메시지나 진행 중인 작업이 있으면 재시작을 보류합니다. 종료를 기다려 설치한 뒤 앱을 다시 실행하며 다시 로그인해야 합니다. ZIP 버전은 설치 파일로 먼저 설치하세요.

이 저장소의 공개 정식 릴리스만 사용합니다. GitHub 로그인·토큰 없이 조회·다운로드하며 동일·낮은 버전과 사전 릴리스는 설치하지 않습니다. 다운로드의 주소·이름·크기·SHA-256을 검사하고 실행 직전에도 해시를 확인합니다.

## 포함된 화면 개선

드롭다운·설정 화면 디자인 통일, 2단계 인증 입력·코드 전송 제거, 알림 **3·4·5초** 및 **보낸 사람 보이기·가리기**, 설치 시 바로가기 선택과 없는 바로가기만 설정에서 추가하는 기능을 포함합니다. NAS 계정 정책은 변경하지 않습니다.

## 검증

Windows WPF 빌드와 C# 회귀 테스트 95개가 통과했습니다. 실제 설치기로 추출한 472개 파일과 최종 설치된 472개 파일의 해시가 모두 원본과 일치했습니다.

공개 경로 다운로드·해시 검사, 기존 앱의 업데이트 버튼을 통한 1.1.3 설치·재실행, Windows 설치 등록 버전 1.1.3을 확인했습니다. 격리된 복사본의 파일을 손상시키고 설치 실패를 주입한 시험에서도 원본 472개 파일 복원 및 시험용 새 파일 제거를 확인했습니다. 설정 외 사용자 파일 320개는 해시가 유지됐으며 설정은 앱의 저장 경로로 기록됐습니다. [상세 검증 기록](https://github.com/SCOTT0318/tempchain-chat/blob/main/docs/VERIFICATION-v1.1.3.md)

실제 NAS 두 계정의 송수신·방 관리와 다른 직원 PC의 업데이트는 별도 현장 확인 항목입니다.
