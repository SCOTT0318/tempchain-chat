# TChat v1.2.4

- 잠금 화면의 입력 안내와 자리수 설명 제거
- 로그아웃 버튼을 내 계정 오른쪽으로 이동
- 왼쪽 메뉴 맨 아래에 설정 배치, 그 위에 잠금 버튼 추가
- 설정의 로그인 유지 설명 및 중복 잠금 버튼 제거
- 대화창의 반복 안내·빈 화면 설명·상시 연락처 수 문구 정리
- 계정에 이메일이 없을 때 불필요한 안내 대신 빈 줄 처리
- 트레이 최소화 안내 제거
- 오류 안내와 채팅방 폐쇄의 영향 확인은 유지
- 저장된 로그인·암호·알림 시간·자동 잠금 설정 유지
