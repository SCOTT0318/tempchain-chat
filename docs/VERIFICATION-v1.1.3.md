검증일: 2026-10-26. Windows 11 x64에서 확인했습니다. 배포 앱의 소스 커밋은 `a8adaa7`입니다.

| 복원 후 독립 비교 | 472개 파일이 원본과 전부 일치, 시험용 새 파일 제거 확인 |
| GitHub 업로드 | EXE·ZIP·체크섬 3개 자산의 GitHub SHA-256이 로컬과 일치 |

실패 복원 시험은 실제 사용자 앱 대신 격리된 복사본에서 실행했습니다. 생산 helper의 복원 코드를 사용했으며 시험 중 실패 안내 팝업만 생략했습니다. 설정 값 변경은 앱의 설정 저장 경로와 구분해서 기록했으며, 사용자 파일 전부가 바이트 단위로 불변이었다고 보고하지 않습니다.

기존 v1.1.2 설치기에서는 특정 리소스 파일 추출 실패가 확인되어 사전 릴리스로 전환하고 최신 정식 업데이트 대상에서 제외했습니다. v1.1.3은 로컬 staging, zlib 압축 및 실제 설치기 추출 비교를 거쳐 게시했습니다.

다른 직원 PC에서의 업데이트와 실제 NAS 두 계정의 송수신·방 관리·새 메시지 알림 도달은 별도 현장 확인 범위입니다.
