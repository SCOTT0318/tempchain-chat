# TEMPCHAIN Chat v1.1.0

Windows 11 x64용 정식 릴리스입니다. v1.1.0-rc.1의 기능 코드를 main에 병합한 `89a9beb`에서 Windows 배포본을 새로 빌드했습니다.

## 다운로드와 업데이트

- [설치 EXE](https://github.com/SCOTT0318/tempchain-chat/releases/download/v1.1.0/TempChainChat-Setup-1.1.0.exe)
- [전체 ZIP](https://github.com/SCOTT0318/tempchain-chat/releases/download/v1.1.0/TempChainChat-1.1.0-win-x64.zip)
- [SHA-256 체크섬](https://github.com/SCOTT0318/tempchain-chat/releases/download/v1.1.0/SHA256SUMS.txt)

저장소는 비공개이므로 다운로드하려면 저장소 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다. .NET 실행 환경을 포함하며 앱과 설치기는 코드 서명되지 않았습니다.

기존 앱을 알림 영역의 **종료**로 완전히 닫고 설치 EXE를 실행합니다. 기존 설치 경로를 갱신하고 사용자 설정을 보존합니다. 업데이트 후 NAS 계정으로 다시 로그인하세요. ZIP은 전체 폴더를 압축 해제한 뒤 실행합니다. 자동 업데이트는 제공하지 않습니다.

## 추가한 기능

- 설정에서 바탕화면·시작 메뉴 바로가기 생성 및 덮어쓰기 확인
- 새 메시지 알림 켜기/끄기, 애니메이션, 소리, 1~60초 표시 시간과 미리 보기
- 다른 방·숨긴 방의 새 일반 메시지 알림 및 클릭 이동
- 비공개/공개 채팅방 생성, 이름·설명 입력, 직원 검색·다중 선택 초대
- 내 참여 나가기와 전체 채팅방 삭제(폐쇄) 구분
- 전체 폐쇄 시 방 이름 재입력·영향 동의·서버 권한 재검사

## 이번 릴리스 검증

- Windows에서 .NET 10 WPF Release 빌드와 자체 포함 win-x64 게시 성공
- C# 회귀 테스트 75개 통과
- scott 환경 Python 테스트 49개 통과. 심볼릭 링크 생성 테스트 1개는 Windows 권한 부족(WinError 1314)으로 실패했으며 해당 검증은 완료하지 못함
- NSIS 3.13 설치기와 ZIP 생성, 배포 파일 472개 및 SHA-256 검증
- 실행 중 앱이 있으면 무인 설치가 종료 코드 2로 중단하는 동작 확인
- 이 PC에서 설치 종료 코드 0, 설치 등록 버전 1.1.0 및 배포 파일 472개 해시 일치 확인
- 기존 사용자 파일 321개 해시 보존, 바탕화면·시작 메뉴 바로가기 대상 확인
- 업데이트 전 사전 버전에서 기존 NAS 세션의 연락처 24명·대화 조회 및 새 설정 화면 표시 확인
- 업데이트 후 설치 앱 재실행 및 로그인 화면 표시 확인

실제 NAS 두 계정의 새 방 생성·초대·송수신·다른 방 알림·나가기·폐쇄와 일반 직원 계정 OTP, 제거는 추가 현장 확인 항목입니다. 정식 릴리스 게시를 이 항목들의 운영 검증 완료로 해석하지 않습니다.

## 지원 범위

앱 실행 중 약 3초 간격 조회 방식입니다. 앱 종료 후 푸시, 스레드·암호화 대화 알림, 파일 전송·화상 통화는 지원하지 않습니다. 메시지 본문은 알림에 표시하지 않습니다.

전체 방 삭제는 NAS의 `Channel.close` 호출에 해당하며 다른 참여자에게도 영향을 줍니다. 물리적 영구 삭제를 보장하지 않으며 NAS 보존 정책을 따릅니다. 기본방·나에게 보내기·일대일·암호화 대화의 관리 작업은 차단합니다. 권한 확인 실패 시 변경을 차단하고 변경 요청을 자동 재실행하지 않습니다.
