# TEMPCHAIN Chat v1.1.2

현재·최신 버전 확인과 자동 업데이트를 추가한 Windows 11 x64 정식 릴리스입니다. 이전에 요청한 메뉴·설정 디자인, 인증 코드 제거, 알림과 바로가기 개선도 함께 포함합니다.

## 버전 확인과 자동 업데이트

- 설정의 **버전 및 업데이트**에 현재 버전·최신 정식 버전·확인 및 다운로드 상태 표시
- **새 버전 자동 확인 및 다운로드** 기본 켜짐. 앱 시작 시와 실행 중 6시간마다 확인하며 설정에서 끌 수 있음
- **업데이트 확인**으로 수동 조회·다운로드, **업데이트 및 재시작**으로 설치 적용
- 작성 중인 메시지나 진행 중인 작업이 있으면 재시작 보류. 설치 후 다시 로그인
- 고정 GitHub 저장소의 정식 릴리스만 사용하며 동일·낮은 버전과 사전 릴리스는 설치하지 않음
- 설치 파일의 HTTPS 주소·이름·크기·SHA-256 확인. 다운로드 및 설치 직전 해시 검증 후 앱 종료를 기다려 설치
- 업데이트 설치 모드는 기존 사용자 설정·바로가기 유무 보존. 설치 버전 확인 후 앱 재실행
- 설치된 앱에서 자동 설치 지원. ZIP 버전은 설치 파일로 먼저 설치

**저장소 공개 전환 필요:** 이 앱은 GitHub 로그인 정보·토큰 없이 공개 릴리스를 조회합니다. 저장소가 비공개인 동안은 직원 앱의 자동 확인·다운로드가 실패하며 기존 앱은 계속 사용할 수 있습니다. 사용자가 저장소를 공개로 전환한 뒤 실제 공개 경로를 사용할 수 있습니다. 저장소 공개 설정은 이번 작업에서 변경하지 않습니다.

## 함께 포함한 UI 개선

- 대화 우클릭·채팅방 관리 메뉴의 둥근 모서리·아이콘·선택 강조와 삭제 항목 구분
- 카드 형태 설정과 선택 목록·체크박스·스크롤 디자인 통일
- 로그인 화면 및 요청 코드에서 2단계 인증 입력·코드 전송 제거. NAS 계정 정책은 변경하지 않음
- 알림 설정: **3·4·5초**, **보낸 사람 보이기·가리기**. 가리기는 직원 이름과 방 이름을 숨기고 메시지 본문은 항상 숨김
- 설치 중 바탕화면·시작 메뉴 바로가기 생성 선택. 설정의 추가 버튼은 해당 바로가기가 없을 때만 활성화

## 검증 범위

Windows WPF 빌드와 C# 회귀 테스트 95개를 검증 대상으로 포함합니다. 새 테스트는 버전 비교, 공개 API 요청, 비공개·요청 한도 오류, 배포 주소 제한, SHA-256, 잘린 다운로드·취소·리디렉션 차단 및 설치 helper 인자 처리를 다룹니다. 이전 UI 개선의 생산 WPF 메뉴·설정·3·4·5초 선택 목록은 오프라인 미리 보기에서 확인했습니다.

저장소 공개 전 직원 PC의 실제 공개 경로 다운로드는 확인할 수 없습니다. 실제 NAS 두 계정의 송수신·새 메시지 알림·방 관리 동작과 다른 PC의 업데이트는 별도 현장 확인 항목입니다.
