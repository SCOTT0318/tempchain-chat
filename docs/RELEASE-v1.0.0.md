# TEMPCHAIN Chat v1.0.0 릴리스 노트

TEMPCHAIN 전용 디자인의 Windows 네이티브 메신저 첫 릴리스입니다. 사내와 외부에서 사용할 HTTPS 접속 경로를 회사 배포본에 고정했습니다.

## 다운로드와 실행

[최신 릴리스 다운로드](https://github.com/SCOTT0318/tempchain-chat/releases/latest)에서 다음 파일을 제공합니다. 저장소는 비공개이므로 접근 권한이 있는 GitHub 계정으로 로그인해야 합니다.

- `TempChainChat-Setup-1.0.0.exe`: 현재 Windows 사용자용 설치 프로그램
- `TempChainChat-1.0.0-win-x64.zip`: 전체 압축 해제 후 `TempChain.Chat.exe`로 실행하는 버전
- `SHA256SUMS.txt`: 최종 배포물의 SHA-256 확인 파일

Windows 11 x64를 대상으로 하며 .NET 실행 환경을 포함합니다. 앱과 설치기는 현재 Authenticode 코드 서명되지 않았습니다. 배포 파일의 SHA-256은 첨부한 `SHA256SUMS.txt`로 확인할 수 있습니다.

기존 개발용·ZIP·설치 앱이 실행 중이면 알림 영역에서 **종료**한 후 설치합니다. 설치기는 실행 중인 창을 감지하면 먼저 종료하도록 안내하며 무인 설치는 종료 코드 2로 중단합니다.

## 주요 기능

- WPF로 직접 구현한 로그인, 직원·대화 목록, 메시지 화면과 입력창
- 제공받은 TEMPCHAIN 원본 로고와 고해상도 앱·트레이·설치 아이콘
- 기존 NAS 계정과 필요한 일회용 인증 코드로 로그인
- 직원·대화 검색, 참여 대화 조회, 일대일 대화 시작과 텍스트 기록·전송
- 활성 화면에서 실제 표시한 대화의 읽음 처리
- 메시지를 보존하는 내 대화 목록 숨기기와 연락처에서 일대일 대화 다시 열기
- 3초 간격 갱신, 트레이 숨김·복원, 중복 실행 시 기존 창 활성화, 선택적 Windows 자동 실행
- 회사에서 중앙 관리하는 접속 경로: 직원의 로그인·대화·설정 화면에 서버 주소와 주소 수정 기능을 표시하지 않음

대화 숨기기는 본인 목록에만 적용하며 메시지를 삭제하거나 다른 참여자의 대화를 제거하지 않습니다. 나에게 보내기 대화는 숨기기 대상에서 제외합니다.

비밀번호를 설정 파일에 저장하지 않으며 로그인 SID는 앱 메모리에서만 유지합니다. 앱을 완전히 종료하면 다시 로그인해야 합니다.

## 지원 범위와 확인 상태

암호화된 대화, 파일 업로드·다운로드, 스레드·스티커·투표·화상회의는 지원하지 않습니다. 현재 갱신은 HTTP 조회 방식이며 별도 백그라운드 푸시와 알림 도달을 보장하지 않습니다.

현재 NAS의 Synology Chat 2.4.8-22204 클라이언트에서 확인한 내부 API를 사용합니다. 외부 개발자용으로 안정성이 보장된 공개 Chat 클라이언트 API가 아니므로 DSM·Chat 업데이트 후 호환성 확인이 필요합니다.

네이티브 자동 테스트 41개와 선택 연동 테스트 45개가 통과했습니다. 최신 설치본에서 실제 NAS 인증, 직원 24명 조회, 나에게 보내기 메시지 전송·재조회를 확인했습니다. 로그인·설정 화면에 서버 주소 항목이 없으며, 설치한 472개 파일의 SHA-256 일치와 기존 사용자 설정 보존을 검증했습니다. 최종 설치기는 앱이 실행 중이면 종료 코드 2로 중단하고 설치 파일·사용자 설정을 변경하지 않는 검사도 통과했습니다.

사외 GitHub 실행 서버에서 HTTPS 인증서, 앱과 같은 POST 방식의 API discovery, 필요한 Chat API 버전 및 미인증 대화 접근 차단을 확인했습니다. [외부 연결 검사 결과](https://github.com/SCOTT0318/tempchain-chat/actions/runs/39919757052). 실제 외부 단말의 계정 인증·직원 두 명 사이 송수신과 제거 검증은 추가 현장 확인 항목입니다.
