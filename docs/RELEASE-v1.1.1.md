# TEMPCHAIN Chat v1.1.1

메뉴·설정 화면 디자인과 로그인·알림·바로가기 동작을 개선한 Windows 11 x64 수정 릴리스입니다.

## 변경 사항

- 대화 우클릭 메뉴와 채팅방 관리 드롭다운에 둥근 모서리, 아이콘, 선택 강조, 삭제 항목 구분 적용
- 설정 화면을 실행 환경·새 메시지 알림·바로가기 카드로 재구성하고 선택 목록·체크박스·스크롤 디자인 통일
- 로그인에서 2단계 인증 입력과 인증 코드 전송 코드 제거. 사용자 이름과 비밀번호만 사용하며 서버의 계정 정책은 변경하지 않음
- 알림 설정을 **3·4·5초 표시 시간** 및 **보낸 사람 보이기/가리기** 두 항목으로 정리
- 보이기는 실제 새 메시지 작성자 이름과 방 이름 표시, 가리기는 둘 다 숨김. 메시지 본문은 항상 숨김
- 기존 알림 시간은 3~5초 범위로 변환. 사라진 알림 설정값은 무시
- 설치 시 바탕화면·시작 메뉴 바로가기 생성을 각각 선택. 무인 설치 기본값은 두 위치 생성
- 설정의 바로가기 추가 버튼은 해당 바로가기가 없을 때만 활성화. 창을 다시 활성화하거나 생성한 뒤 상태 재확인

## 검증 범위

Windows WPF 빌드와 C# 회귀 테스트 76개가 통과했습니다. 인증 코드 미전송, 기존 설정 호환, 알림 이름 숨김 검증을 포함합니다. 오프라인 미리 보기에서 생산 WPF 메뉴·설정 화면과 3·4·5초 선택 목록을 확인했습니다.

실제 NAS 두 계정의 송수신·새 알림 도달·방 생성·초대·나가기·폐쇄는 별도 현장 확인 항목입니다. 앱 종료 후 푸시, 파일 전송·암호화 대화·스레드 알림은 지원하지 않습니다.
