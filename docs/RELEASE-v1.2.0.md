# TChat v1.2.0

- 사용자 프로필 설명의 `이름 | 직급`을 `이름 직급`으로 표시하고 아래에는 이메일 표시
- 알림 표시 시간과 보낸 사람 표시 옵션을 선택 즉시 저장
- 로그인 시 오래된 메모리 설정이 저장된 알림 시간을 덮어쓰던 경로 제거
- 최초 NAS 로그인 후 앱 잠금 암호(6~128자) 설정
- Windows 사용자별 DPAPI로 로그인 정보를 암호화하여 재실행·재부팅·업데이트 후 로그인 유지
- 앱 재실행 시 잠금 화면 표시, 사용하지 않을 때 자동 잠금(기본 5분, 설정에서 1~60분)
- Windows 세션 잠금 연동, Ctrl+L 및 설정·트레이의 수동 잠금
- 잠긴 동안 대화 화면 숨김, 읽음 처리 중지, 알림의 보낸 사람과 방 이름 가리기
- NAS 세션 만료 시 자동 재연결, 전송·방 변경 요청은 자동 재전송하지 않음

## 사용

이전 버전은 로그인 정보를 저장하지 않았으므로 이번 설치 후 최초 1회 NAS 계정으로 로그인하고 앱 잠금 암호를 설정해야 합니다. 이후 앱은 잠금 암호로 열 수 있습니다. 설정에서 잠금 시간과 암호를 변경합니다. 로그아웃 또는 ‘NAS 계정으로 다시 로그인’을 선택하면 저장된 로그인이 제거됩니다. NAS 비밀번호 변경·계정 차단 등 서버에서 인증을 거부하는 경우에는 다시 로그인해야 합니다.

앱 잠금 암호 원문은 저장하지 않습니다. 임의의 salt와 PBKDF2-SHA256 해시를 사용하며 NAS 로그인 정보와 함께 Windows 사용자 계정에 묶어 암호화합니다. 알림·실행 설정은 별도 파일에 보존합니다.

## 검증

코어 회귀 테스트 102개와 별도 WPF 화면 검증을 수행했습니다. Windows DPAPI 재로딩·변조 거부, 암호 검증, 자동 잠금 시간 경계, 로그인 저장 중 알림 설정 보존을 확인했습니다. WPF 실제 컨트롤에서 3초 선택 즉시 저장·창 재생성 후 유지, 암호 설정·오류 암호 거부·정상 잠금 해제, 시작 시 잠금과 대화 화면 숨김을 격리된 가상 계정으로 검증했습니다.

재부팅 후 실제 사용자 계정 로그인 유지와 Windows 잠금 이벤트는 현장 확인 대상입니다.
