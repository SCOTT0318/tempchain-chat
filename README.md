# TChat

TEMPCHAIN 사내 Windows 메신저입니다.

## 1.4.0 · 파일 송수신·잠금 화면 개선

대화 입력창의 **파일 첨부**에서 여러 파일을 선택하고 **보내기**로 한 번에 전송합니다. 파일당 10MB, 한 번에 최대 20개이며 선택 목록에서 개별 제거할 수 있습니다. 파일만 보내거나 텍스트와 함께 보낼 수 있고, 전송한 파일 이름을 대화에 표시합니다. 실패하면 다음 파일 전송을 멈추며 성공한 파일은 선택 목록에서 제거합니다.

파일 메시지의 저장 버튼으로 다운로드할 수 있습니다. 용량 초과 파일은 이름과 한도를 안내하고 정상 파일은 계속 첨부합니다. 잠금 화면은 암호가 일치하면 자동으로 열립니다. 서버 접근 검사기도 함께 갱신해야 합니다. [1.4.0 구현·적용 안내](docs/RELEASE-v1.4.0.md)를 참고하세요.

## 1.3.0 변경

- ERP 그룹 계정만 TChat 로그인·사용 가능, 그룹 제외 시 접근 차단 및 목록 자동 갱신
- ERP 원본 계정 설명·이메일을 1분마다 동기화해 오래된 Chat 프로필 보정
- 잠금 화면 로고 가운데 배치 및 제목 제거
- 사용자 설명의 `이름 | 직급`을 `이름 직급`으로 표시하고 아래에는 이메일 표시
- 이름·이메일로 사용자 검색
- TChat 설치 파일 하나로 배포
- 알림 표시 시간을 선택 즉시 저장하고 업데이트·로그인 후에도 유지
- 첫 로그인 후 앱 잠금 암호 설정, 재실행·재부팅 후 로그인 유지
- 1~60분 자동 잠금, Windows 잠금 연동, Ctrl+L 수동 잠금

## 사용

Windows 11 x64에서 설치 EXE를 실행한 뒤 기존 ERP 계정으로 로그인합니다. .NET 실행 환경이 포함됩니다. ZIP은 전체를 압축 해제해 실행하세요.

설치할 때 바탕화면·시작 메뉴 바로가기를 선택합니다. 설정에서는 없는 바로가기를 추가할 수 있습니다.

알림은 **3·4·5초**, **보낸 사람 보이기·가리기**를 선택합니다. 메시지 본문은 알림에 표시하지 않습니다.

## 업데이트

설정에서 현재·최신 버전을 확인합니다. 자동 확인은 시작 시와 6시간마다 실행하며, 다운로드 후 **업데이트 및 재시작**으로 적용합니다.

1.1.4 이하 앱은 위 설치 파일을 직접 내려받아 업데이트해야 합니다. 1.1.5부터는 TChat 설치 파일로 자동 업데이트를 조회합니다. 설치 경로와 내부 실행 파일명은 유지합니다.

## 개발

.NET 10 SDK와 Windows에서 실행합니다.

```powershell
dotnet build desktop/TempChain.Chat/TempChain.Chat.csproj -c Release
dotnet run --project desktop/TempChain.Chat.Tests/TempChain.Chat.Tests.csproj -c Release
./desktop/scripts/Build-Desktop.ps1 -Version 1.3.0
```

[Windows 앱·개발 안내](desktop/README.md) · [서버 설정](docs/SETUP.md) · [1.3.0 릴리스 노트](docs/RELEASE-v1.3.0.md)

최초 1회 ERP 계정 로그인 후 앱 잠금 암호(숫자 4자리·6자리 또는 문자 포함 6자 이상)를 설정합니다. 이후에는 잠금 암호로 열고 ERP 계정 로그인은 유지합니다. 설정에서 자동 잠금 시간(기본 5분, 1~60분)과 암호를 변경할 수 있습니다. 명시적으로 로그아웃하거나 ERP 계정 비밀번호가 변경된 경우에는 다시 로그인해야 합니다. ERP 그룹에서 제외되면 사용 권한이 종료됩니다.

텍스트 대화·직원 목록·채팅방 관리·읽음 처리·트레이를 지원합니다. 개발 버전 1.4.0에 파일 업로드를 추가했습니다. 암호화 대화·스레드는 미지원이며, 새 메시지는 3초 간격으로 조회합니다. 앱과 설치기는 코드 서명되지 않았습니다.
